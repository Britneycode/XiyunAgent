# XiyunAgent 技术规格

## 运行时

```text
Electron + React
        |
本地 Agent Server
        |
Pi Runtime
        |
模型 Provider / 工具 / 子智能体
```

Electron 负责窗口、设置页和进程生命周期。Agent Server 独立运行，供桌面端、Web 和 CLI 复用。Server 默认只监听 `127.0.0.1`。

推荐技术栈：TypeScript、pnpm workspace、Hono、SQLite、SQLite FTS5、Vitest。

## 模式

### Chat

提供自然对话、个人偏好、学习资料、题目、错题和复习进度。默认只读，写入学习资料或记忆时由记忆服务处理。

### Work

提供本地文件、网页阅读、文档处理和任务记录。第一版不接入邮件、飞书或微信等外部渠道。

### Code

提供当前项目目录内的文件编辑、PowerShell、Git Bash、WSL、Git 和测试。删除、覆盖、提交、推送、部署及访问工作区外路径必须确认。

每个会话固定一个模式和一个工作区。跨模式通过任务交接摘要传递目标、约束、相关文件和用户要求。

## 模型与子智能体

模型注册表记录 Provider、模型、上下文长度、能力标签和可用角色。模型可以标记为 `main`、`subagent`、`vision`、`memory` 或 `embedding`。

子智能体由主 Agent 调度，最多三个并行任务。子智能体只能读取筛选后的相关记忆，不能直接写长期记忆。任务结果使用结构化协议返回：

```json
{
  "status": "completed",
  "summary": "...",
  "artifacts": [],
  "changed_files": [],
  "risks": [],
  "memory_candidates": []
}
```

默认按角色选择模型，用户可以临时覆盖；模型不可用时按授权范围执行备用模型回退。

## 记忆

记忆分为四层：

1. 规则：人格、表达偏好和项目约束，使用 `AGENTS.md`、`CLAUDE.md` 等文件。
2. 事实：用户偏好、项目状态、学习进度和客户信息，带来源、置信度及有效时间。
3. 事件：原始对话、工具调用、任务和文件变化，用于回溯。
4. 索引：SQLite FTS5 和可替换的向量索引，用于检索候选内容。

规则与自动记忆分开。当前用户指令优先于规则，规则优先于事实，事实优先于历史对话。新事实不会覆盖旧事实，而是结束旧事实的有效期。

自动提取异步执行。高价值或高风险候选记忆提示用户确认，普通候选以低置信度保存。支持自然语言查看、修改、普通删除和“彻底忘记”。

## Skill 与插件

Skill 是本地目录或 ZIP 中的工作流定义，包含说明、触发条件、工具声明、模型角色和权限要求。插件通过 Extension API 注册工具、Provider、页面、路由或后台任务。

插件安装和启用分开。插件默认不能访问全局记忆，只能访问当前模式和工作区；网络、后台任务和工作区外路径必须声明权限。

第一版不做在线插件市场，不自动执行远程安装脚本。

## 设置与主题

设置页参考 OpenHanako 的分区方式，包含通用、外观、模型、子智能体、记忆、工作区、权限、安全、Skill、插件和关于。

外观支持浅色、深色、跟随系统、主题色、普通字体、代码字体、字号、行距和界面密度。主题使用设计令牌，支持实时预览、导入和导出；字体缺失时自动回退，不自动下载字体。

## 安全与审计

工具调用、模型调用、记忆访问、文件操作和命令执行记录本地审计日志。日志脱敏且不可由 Agent 修改。高风险操作必须由用户确认。

第一版是本地单用户应用，不需要登录。数据目录可配置，支持加密 ZIP 导出和恢复，不导出 API Key。
